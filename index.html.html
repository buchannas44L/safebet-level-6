Our Product: Responsible Gambling App

SafeBet does not promote betting. Instead, it helps users control their habits using clear limits and friendly alerts.

  • The app is connected to betting websites and apps.
  • Time and money limits are set by the user inside SafeBet.
  • Notifications are sent when a limit is close or passed.
  • Statistics and graphs are shown to explain user behaviour.

These sentences already use the passive voice: limits are set, alerts are sent, statistics are shown.

Elaboration Process – Part 1

This is how the product is planned and designed.

  • Problem identification: the main problem is identified by the team and different ideas are discussed.
  • Research: existing tools are studied and user needs are analyzed.
  • Design: the first screens are designed by UX and UI designers.
  • Planning: all features are organized in a product roadmap and deadlines are set by the project manager.

Each verb is in passive voice: is identified, are discussed, are studied, are analyzed, are designed, are organized, are set.

Process
From idea to clear plan

Elaboration Process – Part 2

Now the app is programmed, tested and released.

  • Development: the app is programmed in JavaScript and Python; security modules are added to protect user data.
  • Testing: the app is tested by real volunteers; bugs are found and are fixed before the release.
  • Release: the first version is released on Android and iOS stores.
  • Feedback: comments from users are collected to improve the product.
